# CC Switch Duo Usage Plugin v1.0.1

**Release date:** 2026-09-18
**Host application:** CC Switch 3.20.3
**Plugin release:** v1.0.1

CC Switch Duo Usage Plugin v1.0.1 completes the Usage Duo budget path while keeping
the host CC Switch application at version 3.20.3.

## Highlights

- API-key identity is stable across independent Switch instances. This is not
  node pairing, cloud synchronization, or a shared global counter.
- Each Switch keeps its own local budget ledger and reservation state. A
  depleted gate stops the request chain before another provider hop receives
  more traffic.
- Streaming responses use protocol-safe cutoff and reservation reconciliation;
  terminal budget errors do not trigger provider failover.
- Usage limits support money (USD/CNY) and normalized tokens.
- Automatic reset can be set to never, every N hours, or every N days. Resets
  advance the local usage window lazily and never delete usage history.
- The card status, dialog, reset controls, and release documentation cover
  English, Simplified Chinese, Traditional Chinese, and Japanese.

## Boundaries

- Enforcement covers traffic that passes through the CC Switch local proxy.
  Direct provider traffic cannot be observed or blocked.
- OAuth/managed credentials do not have a static API key and are not included
  in the API-key budget ledger.
- Limits and reset windows are local to each Switch and are not synchronized
  through cloud configuration.
- This release is unsigned and not notarized. macOS Apple Silicon users may
  see the normal Gatekeeper warning for an unsigned app.
