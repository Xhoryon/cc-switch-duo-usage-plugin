# CC Switch Duo Usage Plugin v1.0.2

**ホストアプリ:** CC Switch 3.20.3  
**プラグインバージョン:** v1.0.2  
**プラットフォーム:** macOS Apple Silicon（署名なし）

## 更新内容

- Usage Duo の予算経路、API Key フィンガープリント、ローカル制限、リセット期間、ストリーミング打ち切りを維持します。
- 公開ソースからディープリンクのテスト/デモページと、認証情報を含む形式のサンプルを削除しました。
- 個人の連絡先をリポジトリの Issue 報告窓口に置き換え、元の CC Switch の MIT 表示を保持します。

制限は CC Switch のローカルプロキシを通る通信だけに適用され、Provider への直接通信は観測・遮断されません。
本リリースは署名・公証されていません。
