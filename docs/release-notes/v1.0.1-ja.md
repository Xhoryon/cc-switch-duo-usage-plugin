# CC Switch Duo Usage Plugin v1.0.1

**リリース日:** 2026-09-18
**ホストアプリ:** CC Switch 3.20.3
**プラグインバージョン:** v1.0.1

CC Switch Duo Usage Plugin v1.0.1 では Usage Duo の予算経路を完成させつつ、ホストの
CC Switch アプリバージョンは 3.20.3 のまま維持しています。

## 主な更新

- API Key の身元を独立した Switch インスタンス間でも安定して識別できます。ノードの
  ペアリング、クラウド同期、共有グローバルカウンターは追加していません。
- 各 Switch は独自のローカル予算台帳と reservation 状態を持ちます。どこかの制限に
  達すると、次のプロバイダーホップへ転送する前にリクエストチェーンを停止します。
- ストリーミング応答はプロトコルに安全な境界での打ち切りと reservation の照合に対応し、
  終端の予算エラーではプロバイダーのフェイルオーバーを実行しません。
- 金額制限（USD/CNY）と正規化トークン制限に対応しています。
- 自動リセットは、リセットしない、N 時間ごと、N 日ごとから選択できます。リセットは
  各 Switch 内で遅延実行され、使用量の履歴は削除されません。
- カードの状態、設定ダイアログ、リセット操作、Release ドキュメントは English、
  简体中文、繁體中文、日本語に対応しています。

## 利用上の境界

- 制限は CC Switch のローカルプロキシを通る通信にのみ適用されます。Provider への
  直接接続は観測も遮断もできません。
- OAuth / 管理対象の認証情報には静的な API Key がないため、API Key 予算台帳には入りません。
- 制限とリセット期間は各 Switch のローカル状態であり、クラウド設定とは同期しません。
- 本リリースは署名・公証されていません。macOS Apple Silicon では、署名なしアプリに
  対する通常の Gatekeeper 警告が表示される場合があります。
