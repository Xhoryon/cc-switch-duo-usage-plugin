# CC Switch Duo Usage Plugin v1.0.1

**發布日期：** 2026-09-18
**宿主應用程式：** CC Switch 3.20.3
**外掛版本：** v1.0.1

CC Switch Duo Usage Plugin v1.0.1 完成 Usage Duo 預算鏈路，同時維持宿主 CC Switch
應用程式版本為 3.20.3。

## 主要更新

- API Key 身分可在彼此獨立的 Switch 實例之間穩定識別。這不是節點配對、雲端同步，
  也不是共享的全域計數器。
- 每台 Switch 都維護自己的本地預算帳本與 reservation 狀態；某一層限額耗盡後，
  會在繼續向下游轉發前停止請求鏈路。
- 串流回應支援協定安全邊界截斷與 reservation 對帳；終止性預算錯誤不會觸發供應商故障轉移。
- 支援金額限額（USD/CNY）與標準化 Token 限額。
- 自動重置可選擇永不重置、每 N 小時或每 N 天。重置只在本地惰性推進用量視窗，
  不會刪除歷史用量。
- 卡片狀態、設定對話框、重置控制項與 Release 文件均涵蓋 English、簡體中文、繁體中文和日本語。

## 使用邊界

- 限額只約束經過 CC Switch 本地代理的流量；直連 Provider 的流量無法觀測或攔截。
- OAuth/託管憑證沒有靜態 API Key，不會進入 API Key 預算帳本。
- 限額與重置視窗屬於每台 Switch 的本地狀態，不會透過雲端設定同步。
- 本版本未簽名且未公證。macOS Apple Silicon 使用者可能會看到未簽名應用程式的系統安全提示。
