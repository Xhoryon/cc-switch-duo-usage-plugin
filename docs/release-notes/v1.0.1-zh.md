# CC Switch Usage Plugin v1.0.1

**发布日期：** 2026-09-18
**宿主应用：** CC Switch 3.20.3
**插件版本：** v1.0.1

CC Switch Usage Plugin v1.0.1 完成了 Usage Duo 预算链路，同时保持宿主 CC Switch
应用版本为 3.20.3。

## 主要更新

- API Key 身份可在相互独立的 Switch 实例之间稳定识别。这不是节点配对、云同步，
  也不是共享全局计数器。
- 每台 Switch 都维护自己的本地预算账本和 reservation 状态；某一层限额耗尽后，
  会在继续向下游转发前停止请求链路。
- 流式响应支持协议安全边界截断和 reservation 对账；终止性预算错误不会触发供应商故障转移。
- 支持金额限额（USD/CNY）和标准化 Token 限额。
- 自动重置可选择永不重置、每 N 小时或每 N 天。重置只在本地惰性推进用量窗口，
  不会删除历史用量。
- 卡片状态、配置对话框、重制控件和 Release 文档均覆盖 English、简体中文、繁體中文和日本語。

## 使用边界

- 限额只约束经过 CC Switch 本地代理的流量；直连 Provider 的流量无法观测或拦截。
- OAuth/托管凭证没有静态 API Key，不进入 API Key 预算账本。
- 限额与重置窗口属于每台 Switch 的本地状态，不通过云端配置同步。
- 本版本未签名且未公证。macOS Apple Silicon 用户可能会看到未签名应用的系统安全提示。
