# CC Switch Duo Usage Plugin v1.0.2

This release keeps the host application at **CC Switch 3.20.3** and ships an
unsigned macOS Apple Silicon build. The source archive and release assets were
reviewed to remove the deep-link test page, credential-shaped examples,
developer-specific contact data, and unrelated repository metadata.

## English

- Keeps the Usage Duo budget path, API-key fingerprinting, local limits, reset
  windows, and streaming cutoff behavior from v1.0.1.
- Removes the repository's deep-link test/demo page and all credential-bearing
  examples from the published source.
- Replaces personal contact metadata with repository issue reporting and keeps
  the original CC Switch MIT attribution.
- Enforcement applies only to traffic routed through the CC Switch local proxy;
  direct provider traffic is not observed or blocked.

## 简体中文

- 保留 v1.0.1 的 Usage Duo 预算链路、API Key 指纹绑定、本地限额、重置周期和串流截断行为。
- 从发布源代码中移除深链接测试/演示页面及所有带凭据形态的示例。
- 将个人联系信息改为仓库 Issue 报告入口，并保留原 CC Switch 的 MIT 署名。
- 限额只对经过 CC Switch 本地代理的流量生效，直连 Provider 的流量不会被观测或拦截。

## 繁體中文

- 保留 v1.0.1 的 Usage Duo 預算鏈路、API Key 指紋綁定、本地限額、重置週期與串流截斷行為。
- 從發布原始碼中移除深連結測試/示範頁面與所有帶有憑證形態的範例。
- 將個人聯絡資訊改為倉庫 Issue 回報入口，並保留原 CC Switch 的 MIT 署名。
- 限額只對經過 CC Switch 本地代理的流量生效，直連 Provider 的流量不會被觀測或攔截。
