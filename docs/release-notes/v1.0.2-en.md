# CC Switch Duo Usage Plugin v1.0.2

**Host application:** CC Switch 3.20.3  
**Plugin release:** v1.0.2  
**Platform:** macOS Apple Silicon (unsigned)

## Changes

- Preserves the Usage Duo budget path, API-key fingerprinting, local limits,
  reset windows, and streaming cutoff behavior.
- Removes the deep-link test/demo page and credential-shaped examples from the
  published source.
- Replaces personal contact metadata with repository issue reporting while
  retaining the original CC Switch MIT attribution.

Limits apply only to traffic routed through the CC Switch local proxy. Direct
provider traffic is not observed or blocked. The build is unsigned and not
notarized.
